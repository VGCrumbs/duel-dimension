# The bundled card database

This folder is the card database Duel Dimension ships inside its own jar and
unpacks here on first run, so the mod works on a machine that has never been
online. It is the same shape as the database the mod used to download.

## What is here

| folder | files | what it holds |
| --- | ---: | --- |
| `cards/` | 13,862 | one JSON per card: name, effect text, type/stats, and a URL for the artwork |
| `sets/` | 691 | one JSON per printed set: code, release date, and its card list |
| `rarities/` | 29 | how each rarity is drawn — this mod's own foil/overlay model |
| `distributions/` | 78 | what a pack of each kind pulls — this mod's own model |
| `rarity_images/` | 23 | the overlay PNGs those rarities are drawn with |
| `db.json` | 1 | which database version this is |

No card artwork is here. Every card names its image as a URL
(`images.ygoprodeck.com`), which the mod fetches per installation and caches
outside this folder, exactly as it always has.

## Where it came from

Two provenances, and they were established by comparing files rather than by
recollection:

- **10,756 of the 13,862 card files, and 357 of the 691 set files, come from
  <https://github.com/CAS-ual-TY/YDM2-DB>** — the database the upstream mod
  downloads at runtime, and the source `db.json`'s `download_link` still names.
- **The remaining 3,106 cards and 334 sets were generated by
  `tools/update_card_db.py` in this project**, from the same upstream that
  YDM2-DB itself is built from: YGOPRODeck's public API.

`rarities/` and `distributions/` are partly upstream's and partly this
project's own design work; they contain no card text at all.

The files are re-serialised rather than copied byte for byte — ours are LF where
YDM2-DB's are CRLF — so do not expect a hash match against upstream. The
*content* of every shared card file but one (`elemental_hero_stratos.json`) is
identical. The Unlicense permits "copy, modify, publish", so reformatting is
within the grant; the point is only that byte-identity is not claimed.

## What is deliberately NOT here

**`alt_art/`** — the extended-art scans for cards Konami never gave a second
passcode. Those come from Yugipedia, whose own file pages say the works are
"copyrighted and unlicensed" and that "Any other uses of this image may be
copyright infringement", so they cannot be redistributed in a mod jar. The mod
still reads `alt_art/` when it is there: run
`tools/fetch_mamo_extended_art.py` and the artwork appears. That is a fetch you
make, not a redistribution we make.

## Your own copy is never overwritten

The unpack writes a file **only when no file of that name already exists**. It
does not compare, merge, or refresh — if a path is occupied, the bundle leaves
it alone and moves on. Your edits, your `alt_art/`, and anything else you put
here survive every launch and every mod update.

`.bundle` records which bundle version was unpacked, so the check is skipped
entirely once it has been done. Delete `.bundle` to make the mod walk the
archive again and restore anything that has gone missing; it still will not
touch a file that is present.

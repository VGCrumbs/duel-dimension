# Duelist skins

Minecraft player skins (64x64, modern format) used for NPC duelist entities.

| File | Duelist | Author |
| --- | --- | --- |
| `joey.png` | Joey Wheeler | JudaiVox |
| `kaiba.png` | Seto Kaiba | xyamorph |
| `yusei.png` | Yusei Fudo | unknown — supplied as `Yusei.png`, no author in the filename |

`yusei.png` was supplied in the legacy 64x32 format and widened to 64x64 by
`tools/install_duelist_skin.py`, using the same mirroring UnderSkin.widen()
applies to a player's own imported skin.

Added 2026-08-04; Yusei 2026-08-08. Authors are recorded from the original filenames as supplied;
if this project is ever distributed publicly, confirm permission with each
author first — fan skins are not automatically licensed for redistribution.
